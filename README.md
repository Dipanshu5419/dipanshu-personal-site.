# Dipanshu Sahu — Personal Website

A responsive, monochrome personal website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content and sections
- `styles.css` — layout, responsive styling, abstract artwork and poster-card designs
- `script.js` — dark/light toggle, current year, gentle reveal animations and social-link setup

## Preview locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Add your social links
Open `script.js` and replace the empty strings in `socialLinks` with your public profile URLs.

## Publish with GitHub Pages
1. Create a new public repository on GitHub, for example `dipanshu-personal-site`.
2. Upload `index.html`, `styles.css`, `script.js` and `README.md` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. After GitHub finishes publishing, your site will be available at `https://YOUR-USERNAME.github.io/dipanshu-personal-site/`.

You can use a different repository name; the published URL will reflect it.
